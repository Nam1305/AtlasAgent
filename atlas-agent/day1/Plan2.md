# Day 1 — Foundations

Short, self-contained demos used in Week 0 to build intuition for
LLM-based systems before adding agents on top.

- `demo_01_basic.py` — single message to the LLM.
- `demo_02_roles.py` — system / user / assistant roles.
- `demo_03_tokens.py` — token counting and context window.
- `demo_04_structured.py` — structured output via JSON mode.
- `demo_05_gateway.py` — calls the model gateway rather than the SDK.
